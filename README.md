# Linux Security Lab

## Project Overview

This project demonstrates Linux server administration and security hardening techniques implemented in a practical lab environment.

The objective was to configure and secure an Ubuntu Server while implementing industry-standard security controls and performing network traffic analysis.

---

## Technologies Used

- Ubuntu Server
- OpenSSH
- WinSCP
- UFW Firewall
- Google Authenticator MFA
- Nginx
- HTTPS / TLS
- Wireshark
- tcpdump

---

## Skills Demonstrated

### User Administration
- Created and managed multiple Linux user accounts
- Configured administrative privileges using sudo

### Secure Remote Access
- Configured SSH key-based authentication
- Disabled insecure password-based authentication
- Hardened SSH configuration

### Multi-Factor Authentication
- Implemented MFA using Google Authenticator
- Verified secure login process

### Firewall Configuration
- Configured UFW firewall rules
- Restricted access to required services only

### Web Security
- Configured Nginx web server
- Implemented HTTPS using SSL/TLS certificates
- Compared encrypted and unencrypted traffic

### Network Analysis
- Captured and analyzed traffic using Wireshark
- Investigated ICMP, TCP and DHCP traffic
- Analyzed the DHCP DORA process
- Used tcpdump for terminal-based packet captures
